Build Menu XML Format
====================

The build menu is fully customizable via Build > Customize. Edit build_menu.xml
or use the Customize dialog to add commands, menus, and variables.

File location
-------------
- Custom: settings folder (e.g. ~/.radiant/<version>/<game>/build_menu.xml)
- Default: gamepack's default_build_menu.xml or AppPath/<game>/default_build_menu.xml

XML structure
-------------
Root element: <project version="2.0">

  <tool name="name">...</tool>   - custom variable definition
  <build name="Menu Name">      - menu item
    <cmd>...</cmd>              - command line (can have multiple)
  </build>

Variables (use [Name] in commands)
----------------------------------
Predefined:
  RadiantPath    - editor installation path
  ExecutableType - platform suffix (e.g. x86_64)
  EnginePath     - game engine path
  UserEnginePath - user-configured engine path
  ExtraResourcePaths - -fs_pakpath args for extra resources
  GameName       - current game name
  MapFile        - full path to current map (.map or .reg for region)
  MapDir         - directory containing the map
  MapName        - map filename only
  BspFile        - output .bsp path (same base as MapFile)
  MonitorAddress - build monitor (when enabled)
  VolumetricFogConfig - path to fog config (when applicable)

  MapsrcDir      - same as MapDir (for map sources: .map, .bak, .prt, .srf)
  BspOutputDir   - content/maps (sibling of mapsrc, for final BSP)
  BspOutputFile  - content/maps/[MapName].bsp
  CopyBspCommand - platform-specific command to copy BspFile to BspOutputFile
                   (add as final <cmd> to copy BSP from mapsrc to content/maps)

Custom (define in <tool>):
  <tool name="q3map2">"[RadiantPath]q3map2.[ExecutableType]"</tool>
  <tool name="arghrad">"[RadiantPath]arghrad"</tool>

Example command
---------------
  [q3map2] -bsp "[MapFile]"

Becomes:
  "C:\Radiant\q3map2.exe" -bsp "C:\maps\mymap.map"

Use quotes around paths (MapFile, etc.) in case of spaces.

Mapsrc / content/maps layout
----------------------------
To keep map sources (.map, .bak, .prt, .srf) in mapsrc/ and the final BSP in
content/maps/:
  1. Save maps to mapsrc/ (e.g. mapsrc/mymap.map)
  2. Add [CopyBspCommand] as the final <cmd> in each build:
     <cmd>[q3map2] -meta "[MapFile]"</cmd>
     <cmd>[q3map2] -vis "[MapFile]"</cmd>
     <cmd>[q3map2] -light "[MapFile]"</cmd>
     <cmd>[CopyBspCommand]</cmd>
  q3map2 writes BSP alongside the map; CopyBspCommand copies it to content/maps/.

Legacy format (buildmenu)
-------------------------
Older <buildmenu> root with <menu name="..."> and <command cmd="..."> is
supported for compatibility. Prefer the <project> format for new configs.
